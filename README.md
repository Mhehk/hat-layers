# Hat Layers

Minecraft **1.21.11** için Fabric modu. İstemcide takip edilen yakındaki oyuncuların TAB kafa katmanını gösterir ve kafa ikonuna küçük bir `*` ekler. Oyuncu uzaklaştığında katman ve işaret kaybolur; yüz görünür kalır.

## Kurulum

1. **Fabric Loader 0.19.3+** ve **Java 21+** kullan.
2. [Hat Layers 1.2.0'ı indir](https://github.com/Mhehk/hat-layers/releases/latest).
3. JAR dosyasını oyun profilinin `mods` klasörüne koy ve oyunu yeniden başlat. Eski sürüm varsa kaldır.

Yalnızca istemciye kurulur. **Fabric API gerekmez.**

## Komutlar

- `/hatlayers` — Takip edilen oyuncuları listeler.
- `/hatlayers OyuncuAdı` — Oyuncunun mesafesini ve katman durumunu gösterir.
